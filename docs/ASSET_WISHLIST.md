# 퀄리티를 높이기 위해 필요한 에셋

지금 게임에서 **코드로 만든 임시 모형**이거나 **다른 그림체에서 빌려 온 것**이라 눈에 띄게 아쉬운 것부터 순서대로 적었다.
받은 에셋은 한 곳만 바꾸면 들어가게 해 두었다(아래 "바꿀 곳").

## 공통 형식(모든 3D 에셋)

- **glb 한 파일**(텍스처 포함), 1단위 = 1 m. 원점은 발바닥(바닥) 가운데, 앞은 +Z(Blender에서는 -Y 앞으로 내보내기 = glTF +Z).
- 그림체: 이번 꼬마 요정·산타처럼 **둥글고 부드러운 저폴리 장난감 느낌**, 정점 색 또는 작은 텍스처(1024 이하).
- 크기 목표: 사람 한 명 1.5만 삼각형 이하, 소품 3천 이하(학교 PC·태블릿 4인 30 FPS).
- 사람·동물은 **뼈대 + 동작 포함**. 뼈 이름은 꼬마 요정과 같으면 가장 좋다(`Hips·Spine·Head·UpperArm.L/R·Forearm.L/R·Hand.L/R·Thigh·Shin·Foot`, 손에 `Grip.L/R`).
- 외부에서 가져온 것이면 **CC0만**(출처·라이선스 링크를 같이 주세요). 직접 만들었거나 생성 도구로 만든 것은 사용권만 확인.
