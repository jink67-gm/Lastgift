# 교사용 수업 안내 · 〈자정의 마지막 선물〉

초등 3~6학년, **한 팀 2~4명**이 기기를 하나씩 들고 같은 이야기를 함께 푸는 협동 게임이다.
글과 대사가 없다. 학생은 화면의 몸짓·소품·표식만 보고 알아챈다. **미리 줄거리를 설명하지 않는다.**

| 항목 | 내용 |
|---|---|
| 주소 | https://jink67-gm.github.io/Lastgift/ |
| 시간 | 팀 시계 30분(연출 동안은 멈춤) + 연출 약 5분 → **한 차시(40분)** 안. 시간 초과가 나도 「다시 하기」로 그 장부터 |
| 기기 | 노트북·크롬북·웨일북(키보드), 태블릿(터치). 브라우저는 **크롬·엣지·웨일** 권장(사파리는 실기기 확인 전) |
| 인터넷 | 처음 연결할 때만 인터넷이 필요하다. 놀이 데이터는 **같은 와이파이 안에서 기기끼리** 오간다 |
| 개인정보 | 실명·로그인 없음. 요정 별명이 저절로 붙는다. 방은 3시간 뒤 사라진다 |

## 1. 수업 전 (10분)

1. 팀마다 **방장 기기 하나**를 정한다(선생님 노트북이나 학생 기기 하나). 나머지는 참가자.
2. 기기마다 주소를 한 번 열어 첫 화면이 뜨는지 본다(처음엔 모델을 내려받느라 몇 초 걸린다).
3. 느린 기기: 오른쪽 위 **톱니 → 그래픽: 낮음**. (자동이면 시작 3초 뒤 느리면 저절로 낮아진다.)
4. 필요한 학생은 톱니에서 **글씨 크게 · 움직임 줄이기(화면 흔들림) · 눈발 줄이기 · 소리**를 켠다.
5. 소리: 기기마다 첫 키나 첫 터치 뒤에 켜진다. 교실이 시끄러우면 톱니 → 소리 끄기.

## 2. 시작

### 방장 기기

```
https://jink67-gm.github.io/Lastgift/?host&new
```

- **`&new`를 꼭 붙인다(수업마다 새 방).** 붙이지 않으면 같은 기기의 지난 방(3시간 안)을 이어서 연다 — 지난 반 학생 자리가 남아
  새 학생이 들어오지 못한다(「이미 시작한 방이에요」).
- 화면에 **방 코드(다섯 글자)·초대 링크·「링크 복사」·「시작」**이 뜬다.

### 참가자 기기

- 방장이 복사한 초대 링크를 메신저·학급 게시판으로 보낸다. 또는 칠판에 적는다:
  `https://jink67-gm.github.io/Lastgift/?join=방코드`
- 들어오면 방장 화면 대기실에 그 요정의 **모자 색·별명**이 생긴다(초록 점 = 연결됨).

### 시작

- 2~4명이 모두 들어오면 방장이 **「시작」**. 시작한 뒤에는 새 기기가 들어올 수 없다(같은 기기는 다시 들어올 수 있다).
- 처음 37초 연출(단체사진 → 썰매 불시착)이 나오고 0장이 시작된다. 장이 끝나면 **모든 화면이 저절로 다음 장으로** 넘어간다.

## 3. 조작 (학생에게는 이것만 알려 준다)

| 기기 | 움직이기 | 행동(들기·놓기·건네기·누르기) |
|---|---|---|
| 키보드 | WASD 또는 방향키 | **E** (길게 누르기도 있다) |
| 태블릿 | 화면 왼쪽 아무 곳을 누른 채 끌기 | 오른쪽 아래 **둥근 단추** |

- 지금 누르면 무엇이 되는지는 **그림**으로 뜬다(키보드: 화면 위 [E] + 그림, 태블릿: 단추 안 그림).
- 연출은 「건너뛰기」(키보드 Esc)로 넘길 수 있다. 처음엔 건너뛰지 않기를 권한다(이야기의 단서).

## 4. 하는 동안 생길 수 있는 일

| 화면 | 뜻 | 할 일 |
|---|---|---|
| 시계 옆 일시중지, 「방장과 연결이 끊겼어요. 다시 연결하는 중…」 | 방장 기기가 꺼졌거나 탭이 숨었다 | 방장 기기에서 **같은 주소를 다시 연다(`&new` 없이 `?host`)** → 같은 방·같은 장으로 이어지고 참가자는 저절로 다시 붙는다 |
| 대기실 모자 옆 점이 회색 | 그 참가자가 끊겼다(그 요정은 들던 것을 내려놓고 멈춘다) | 그 기기에서 **초대 링크를 다시 연다** → 같은 자리로 돌아온다. 한 명만 남으면 팀 시계가 멈춘다 |
| 모래시계 + 「다시 하기」 | 팀 시계 0초 | 「다시 하기」 → 그 장 처음부터(시간은 그 장 시작 때로 돌아간다) |
| 장면이 끊겨 보인다 | 기기가 느리다 | 그 기기만 톱니 → 그래픽: 낮음 (다른 기기와 상관없다) |
| 「방을 찾을 수 없어요」 | 코드 오타이거나 방이 사라졌다(3시간) | 방장 화면의 링크를 다시 복사해 보낸다 |
| 계속 연결이 안 된다 | 학교망이 기기끼리 연결을 막는 경우(일부 무선망) | 아래 「한 기기에서 둘이」로 바꾼다. 정보부장·업체에 "같은 와이파이 기기 간 WebRTC 허용"을 문의 |

**한 기기에서 둘이(연결 문제가 있을 때)**: 주소 `https://jink67-gm.github.io/Lastgift/` 를 그냥 연다.
1P = WASD + E(터치도 1P), 2P = 방향키 + Enter. 한 키보드에 둘이 앉는다.

## 5. 끝내기

- 6장 끝 장면이 지나면 **「처음부터」** 단추가 뜬다(방장 화면). 다시 하려면 누르고, 끝이면 그냥 둔다.
- 수업 시간이 끝나도 중간에 그만둘 수 있다. **방장 기기의 같은 주소(`?host`, `&new` 없이)를 3시간 안에 다시 열면 그 장부터 이어진다.**
  다른 반이 쓰기 전에 이어 하려면 그 기기를 그 팀이 쓰게 한다.
- 탭을 닫으면 끝이다. 따로 지울 것은 없다(방은 3시간 뒤 저절로 사라진다).
- 다음 반은 다시 **`?host&new`**.

## 6. 끝난 뒤 (선택)

- 학생에게 **한 문장 질문**: "유나에게 간 선물은 누가 준 걸까?", "콩이는 누구와 살게 됐을까?", "산타 스노글로브 속 뼈다귀는 누구를 위한 걸까?"
  — 관찰지와 질문 목록은 `docs/CLASSROOM_TEST.md` 2절.
- 플레이 기록(장별 놀이 시간·FPS): 기기마다 톱니 → **기록 → 복사**. 다음 수업 전에 **기록 → 지우기**.

## 수업 전에 혼자 점검하기(관리자 모드)

주소 끝에 `?admin`을 붙여 연다: `https://jink67-gm.github.io/Lastgift/?admin`
왼쪽 위 보라색 **「관리」** 단추를 누르면:

| 단추 | 하는 일 |
|---|---|
| 이야기 모드 처음부터 / 이어서 | 0장(첫 연출)부터 6장까지 이어서. 처음부터는 이 기기의 이야기 저장을 지운다 |
| 0장~6장 | 그 장 하나만 처음부터(그 장의 첫 연출 포함) |
| 바로 끝내기(끝 장면 보기) | 지금 장을 마친 것으로 → 끝 장면이 나온다(이야기 모드면 다음 장으로) |
| 연출 건너뛰기 | 지금 나오는 연출을 넘긴다 |
| 이 장 처음부터 | 지금 장의 저장을 지우고 다시 |
| 관리자 모드 끄기 | 단추를 없앤다 |

혼자 두 요정을 움직일 수 있다: 1P = WASD + E, 2P = 방향키 + Enter(한 키보드). 한 번 켜면 그 창(탭)에서는 장이 넘어가도 계속 켜져 있다.
학생 화면에는 보이지 않는다(주소를 알아야 켤 수 있다). 관리자 모드는 이 기기의 저장만 지우고, 여러 기기 방에는 쓰지 않는다.
