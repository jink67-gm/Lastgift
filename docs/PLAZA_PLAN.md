# 광장 다시 짜기 (안 A, 2026-11-27 결정 · 같은 날 완료)

그림: `docs/screens/plaza-plan/plan_a.png` · 지금 광장: `before_top.png`, `before_wide.png`, `before_game.png`.

## 왜 바꾸나(지금 광장이 어색한 까닭)

1. 40 × 28 m가 거의 다 단색 흰 바닥이고 가운데가 비었다. 시선이 모일 중심이 없다(가운데 가로등 하나뿐).
2. 칼로 자른 직사각형 + 남쪽 울타리 한 줄 = 무대 세트 느낌. 광장 밖은 흰 평면(1·3·4장에는 있는 산·숲·하늘 배경이 없다).
3. 크기·그림체가 섞였다: 사람 크기 통나무집, 요정 크기 공방, 다른 그림체(Tiny Treats) 집, 상자 시계탑.
4. 배달 표식 넷이 네 귀퉁이에 흩어져 이야기와 따로 논다(유나네 표식은 서쪽, 1장 유나네 골목은 북동쪽).
5. 공방·썰매·산타·창고·눈길이 북쪽 가장자리에 몰렸다.

## 같이 바뀌는 것

- 0장: 표식·선물·재봉틀·시작 자리, 처음 전체 구도 카메라.
- 프롤로그: 불시착 자리, 요정이 떨어지는 자리, 산타·도토 자리, 단체사진 구도.
- 5·6장: 같은 광장(썰매 기준 자리는 저절로 따라온다), 단체사진 구도.
- 시험: 위 장들의 자리 숫자를 쓰는 브라우저 시험(0장·프롤로그·5·6장·여러 기기).

## 순서

1. 광장 모양·트리·골목·둘레 벽·집·배경(장면과 충돌체) → 위에서 본 지도·게임 화면으로 확인
2. 0장 자리(표식·선물·재봉틀·시작·카메라) + 시험
3. 프롤로그·단체사진·5·6장 자리 + 시험
4. 다듬기: 돌 포장 무늬, 가로등·돌담·화단·노점, 화면 촬영

화면: `after_ch0_wide.png`(처음 전체 구도), `after_ch0_play.png`, `after_prologue_photo.png`(단체사진 뒤 큰 트리),

- 썰매는 돌리지 않았다(5·6장 양말·가방·좌석·연출 사진기가 "썰매 남쪽 = 앞" 기준). 자리 (3.6, −6.6).
- 산타는 썰매 북쪽이 아니라 **앞코 남쪽**(6.2, −4.3): 북쪽에 서면 유나네 골목 표식을 가렸다.
- 도토는 썰매 날 남쪽 뒤(2.2, −4.75), 프롤로그에서는 썰매 꼬리 남쪽 눈 속에서 튀어나온다(사진기가 트리 가지 속에 들어가던 것 고침).
- 5장 배달 가방은 양말 **동쪽**(양말과 산타 사이 앞쪽, 4.0, −2.8): 서쪽에 두면 트리 화단에 붙어 가방 연출 사진기가 트리 속에 들어갔다.
- 사람 집은 **먼 쪽 골목(유나네·할머니 댁) 양옆에만**. 카메라 쪽 골목(수선집·민재네)은 집 대신 낮은 울타리(집이 광장을 가렸다).
- 둘레 가로등은 **먼 쪽 반원에만**(카메라 쪽에 세우면 화면 앞에 검은 기둥).
- 닫힌 노점은 **서쪽 둘레**(−12.6, 3.6): 남동에 두면 사진기에서 뒷면(밋밋한 상자)만 보였다.
- 공방은 북쪽 둘레에 반쯤 걸친 자리(−7.6, −14.2), 앞면이 광장을 본다.
- 시계탑 (1.5, −22.5). Tiny Treats 집은 뺐다(통나무집 한 그림체).
- 바닥: 동심원 + 바퀴살 돌 포장 줄눈, 카메라 쪽 둘레에 무릎 높이 돌담, 둘레 눈둑(골목 입구는 비움), 1·3·4장과 같은 산·숲·하늘 배경(0·5·6장).
