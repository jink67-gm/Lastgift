# 교실 시험 안내 (STEP 08)

명세서 §11 STEP 08 통과 기준: **첫 팀 실제 조작 시간, 프레임, 글씨·아이콘 기록**.
이 문서는 실제 교실(또는 리허설)에서 그 기록을 모으는 순서와 표다. 자동 시험으로 확인한 것은 맨 아래에 있다.

## 1. 준비

| 기기 | 주소 | 입력 |
|---|---|---|
| 방장(선생님 노트북 또는 학생 기기 하나) | https://jink67-gm.github.io/Lastgift/?host&new (수업마다 새 방, `docs/TEACHER_GUIDE.md`) | 키보드 WASD + E |
| 참가자 1~3대 | 방장 화면의 초대 링크(또는 `?join=코드`) | 노트북·웨일북은 키보드, 태블릿은 왼쪽 스틱 + 오른쪽 행동 단추 |

- 시작 전에 기기마다 오른쪽 위 톱니 → **기록 → 지우기**(지난 시험 기록을 비운다).
- 느린 기기는 톱니 → **그래픽: 낮음**. 자동이면 시작 3초 뒤 느리면 저절로 낮음이 된다.
- 필요하면 **움직임 줄이기**(화면 흔들림·카메라 이동, 다음 장부터)·**글씨 크게**·**눈발 줄이기**.

## 2. 하는 동안: 무언 이해도 관찰지

설명하지 않고 지켜본다. 학생이 **화면의 행동만 보고** 알아챘으면 O, 친구·선생님 설명 뒤에 알았으면 △, 끝까지 몰랐으면 X.
알아챈 순간 무엇을 보고 알았는지(시선·소품·손짓) 한 줄로 적는다.

| 장 | 물어볼 것(끝난 뒤 한 문장으로) | O/△/X | 무엇을 보고? |
|---|---|---|---|
| 0장 | 선물 다섯 개가 어디로 가야 하는지 그림 표식으로 알았나 | | |
| 1장 | **누구에게 가는 선물인지**(유나), 지우가 왜 지도를 그려 줬는지 | | |
| 1장 | 소리를 끄고도 유나와 지우를 구분했나(명세서 STEP 04) | | |
| 2장 | **언제 교대하면 되는지**(지친 손 털기·노란 교대 표시) | | |
| 2장 | 빨간 코트 장면: 재봉틀이 누구에게 무엇을 해 줬는지 | | |
| 3장 | **콩이가 누구와 사는지**(민재네 식구가 데려감) | | |
| 4장 | 할머니가 왜 사진을 찍는지(작년 사진과 포개짐) | | |
| 5장 | 양말이 왜 비어 있었는지, 네 빛이 무엇인지 | | |
| 6장 | 산타 스노글로브 속 뼈다귀가 누구를 위한 것인지 | | |

## 3. 끝난 뒤: 첫 팀 기록지

1. 기기마다 톱니 → **기록 → 복사** → 공유 문서나 메모에 붙여 넣는다(표: 날짜·시각·장·역할·인원·놀이·연출·대기·평균FPS·느린5%·품질·재시도·마침·화면·터치·브라우저).
   - **놀이** = 요정이 움직일 수 있던 시간(실제 조작 시간), **연출** = 장면을 본 시간, **대기** = 일시중지·시간 초과·연결 끊김.
   - **느린5%** = 가장 느린 프레임 5%의 FPS. 30 이하면 끊겨 보인다.
2. 아래 표에 옮긴다.

|---|---|---|---|---|---|---|---|
| 0장 | 3분 | | | | | | |
| 1장 | 4분 | | | | | | |
| 2장 | 5분 | | | | | | |

3. 글씨·아이콘: 교실 뒤쪽에서 화면 위 시계·팀 모자 칩·행동 안내가 읽히는지, 태블릿 행동 단추가 손가락에 맞는지 기기마다 O/X.

## 4. 감상(연출) 길이

모든 연출은 「건너뛰기」(또는 Esc)가 있고, 팀 시계는 연출 동안 흐르지 않는다. 첫 연출(그림책·봉투·단체사진)은 한 시도에 한 번만 나온다.

| 연출 | 길이 | 언제 | 조정 후보(관찰 결과를 보고 정한다) |
|---|---|---|---|
| 프롤로그(단체사진·불시착) | 37.1초 | 새 시도 0장 앞 | 길면 사진 뒷면 부분을 줄인다 |
| 0장 끝 → 1장 | 1.8초 | | |
| 1장 지우 카드 그림책 | 17.2초 | 1장 처음 | |
| 1장 끝(유나 고래 그림) | 약 11초 | | |
| 2장 끝 빨간 코트 | 7초(영상이면 영상 길이) | | |
| 3장 입양 장면 | 36초 | | 가장 긴 장 끝 장면: 지루해하면 담요·물그릇 부분을 줄인다 |
| 4장 봉투·작년 사진 | 11.6초 | 4장 처음 | |
| 4장 끝 사진 | 19초 | | |
| 5장 산타와 단체사진 | 16.4초 | 5장 처음 | |
| 5장 가방·네 빛 | 20.4초 | | |
| 6장 끝(기억 다섯·뼈다귀·장갑) | 41초 | | 마지막 장면이라 그대로 두는 것을 우선 |
| **합계** | **약 3분 40초** | 놀이 목표 27분 중 | |

관찰지에서 학생들이 「건너뛰기」를 누른 장면, 화면에서 눈을 뗀 장면을 적어 두면 줄일 곳을 정할 수 있다.

## 5. 자동으로 확인한 것(이 저장소의 시험, 실제 기기 아님)

- **화면 점검**(`tests/e2e/ui-audit.spec.ts`): 1280×720·1366×768·1920×1080·iPad 가로 1024×768·안드로이드 태블릿 1280×800·태블릿 세로 768×1024,
  글씨 크게 켠 1366×768·1024×768에서 0~5장 놀이 화면 + 프롤로그·그림책·봉투·2장 고르기·6장 끝 화면.
  보이는 글씨 14px 이상, 누르는 단추 44×44px 이상, 위쪽 요소끼리 겹침 없음, 영어 문구 없음(E·Enter·Esc·WASD·FPS 제외) → **모두 0건**.
- **화면 위 요소 크기**(3장): 시계·팀 칩 121×40(글씨 크게 146×50), 키 안내 108×56, 설정 52×52, FPS 131×28, 태블릿 행동 단추 96×96·스틱 112×112.
- **교차 접속**(`tests/e2e-net/team.spec.ts`): 노트북 키보드 방장 + 태블릿 터치만 참가자(스틱 이동·행동 단추·방장 이동이 태블릿 화면에).
- **프레임**(`npm run test:perf`, 1366×768): 이 컨테이너는 그래픽 카드 없이 소프트웨어로 그려서 수치가 실제보다 아주 낮다. **비교용**:

| 장 | 보통 평균/느린5% | 낮음 평균/느린5% |
|---|---|---|
| 0장 | 2.0 / 1.5 | 7.2 / 5.0 |
| 1장 | 2.0 / 1.7 | 10.4 / 5.5 |
| 2장 | 19.6 / 15.0 | 33.6 / 29.9 |
| 3장 | 2.4 / 2.0 | 8.8 / 6.0 |
| 4장 | 2.4 / 1.9 | 11.0 / 6.0 |
| 5장 | 2.2 / 1.7 | 6.6 / 5.5 |
| 6장 놀이 | 2.5 / 1.8 | 7.0 / 6.0 |
| 6장 회상(스노글로브 속 기억) | 1.5 / 1.2 | 8.3 / 4.0 (고치기 전 4.0 / 3.3) |

  - 낮음이 보통보다 3~5배 빠르다(해상도 절반·그림자 끔·눈송이 적게). 2장은 배경(숲·산·하늘)이 없어 훨씬 가볍다.
  - 회상: 보통은 놀이보다 약 40% 느려졌다 → 낮음에서 회상 그림 해상도 720→400, 번진 테두리 빛 빼기, 유리가 다 덮은 동안 뒤 장면을 한 화면 걸러 그리기 → 낮음 회상이 놀이보다 빨라졌다.
